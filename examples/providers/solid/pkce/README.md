# Solid Pod login

Replace `your_server` and `your_name` with your server url and login name registered with the Solid community server.

The server url is needed for providing a client-id.json so the Solid server can accept your client. Other servers may offer different means of (auto-)registration.

An example user information card response in Turtle format can be found in tests/turtle-dot-after-named-uri.
